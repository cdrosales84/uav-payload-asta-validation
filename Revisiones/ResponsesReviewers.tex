\reviewersection
The manuscript addresses an important problem in UAV transportation of cable-suspended payloads, and the use of a flexible-cable simulator together with the release of source code are positive aspects. However, the current conclusions are not supported because the mathematical formulation, stability analysis, public implementation, and reported performance metrics are not mutually consistent.

\begin{point}
The controller implemented in the public code is substantially different from the controller analysed in the manuscript. The code uses saturated position feedback and an additional payload-velocity feedback term absent from Eq. (8); the sign of the quasi-static cable reference differs from Eq. (12); additional filters, saturation, and a leaky integral are introduced; and the inner compensator acts only on the horizontal channels. Most importantly, the manuscript adapts the model parameters associated with \(\kappa_u\) and \(\kappa_v\), whereas the code adapts the super-twisting gains \(K_1\) and \(K_2\). Therefore, the simulations do not validate Eqs. (29)–(40) or Theorem 2.
\end{point}


\begin{reply}
The authors thank the reviewer for the positive feedback. We thank the reviewer for this careful comparison between the manuscript and the released code. The reviewer is right: the previous code and the previous manuscript described different controllers, and the earlier simulations did not validate the adaptation law or Theorem~2. We have rewritten both so that they describe exactly the same controller. The new script (\texttt{sim\_payload\_asta.m}) implements only the equations of Section~2, each line tagged with its equation label, and all parameters are read from a single configuration file (\texttt{cfg\_paper.m}) that is saved with every result. All figures and tables were regenerated with this code. The specific discrepancies were resolved as follows.
 
\begin{enumerate}%[leftmargin=*,label=(\roman*)]
\item \textbf{Saturated position feedback and payload-velocity term.} Both have been removed. The outer loop now implements Eq.~(\XX) exactly,
\begin{equation*}
\mathbf{v}_{\mathrm{base}}=\dot{\mathbf{x}}_d+\begin{bmatrix}\dot{\mathbf{h}}_h^\star\\0\end{bmatrix}+K_{\mathrm{traj}}\,\tilde{\mathbf{x}} .
\end{equation*}
The feedforward term $\dot{\mathbf{h}}_h^\star$ is new in the manuscript: since $\dot{\mathbf{x}}=\dot{\mathbf{x}}_l+\dot{\mathbf{h}}$, the UAV must move at the payload reference velocity plus the rate of the quasi-static cable inclination. Omitting it produces a steady-state tracking error proportional to the reference jerk.
 
\item \textbf{Sign of the quasi-static cable reference.} The sign in the code was correct and the manuscript was wrong. With $\mathbf{h}=\mathbf{x}-\mathbf{x}_l$, the horizontal force balance on the payload gives, to first order, $\ddot{\mathbf{x}}_{l,h}=(g/l)\,\mathbf{h}_h$. Hence
\begin{equation*}
\mathbf{h}_h^\star=\frac{l}{g}\,\ddot{\mathbf{x}}_{d,h},\qquad \dot{\mathbf{h}}_h^\star=\frac{l}{g}\,\dddot{\mathbf{x}}_{d,h},
\end{equation*}
i.e., the UAV leads the payload. Eq.~(\XX) and Assumption~3 have been corrected. Both $\mathbf{h}_h^\star$ and $\dot{\mathbf{h}}_h^\star$ are now computed analytically from the reference, not by numerical differentiation.
 
\item \textbf{Filters, saturation and leaky integral.} The saturation of the swing-compensation term and the leaky integrator have been removed. The sliding-surface integral is now a pure integral, as in Eq.~(\XX). Four first-order discrete filters remain, applied to the payload tracking error, the yaw error, the kinematic command and the numerical derivative of the velocity reference. They are now declared in a new subsection, ``Discrete-time implementation'' (Section~\XX), with their coefficients and equivalent time constants (8.6--60~ms, all below three control periods; Table~\XX).
 
\item \textbf{Channels of the inner compensator.} The manuscript now states that the compensator acts on the two horizontal velocity channels, expressed in the UAV yaw frame in which the model of Ref.~[\XX] is defined. The vertical and yaw channels receive the kinematic command directly. The model, the regressor and the stability analysis have been rewritten for $n=2$, with $\bm{\phi}\in\mathbb{R}^{2\times4}$ and $\bm{\theta}\in\mathbb{R}^{4}$, and the dimensions of every term are stated explicitly.
 
\item \textbf{Adapted quantities.} The reviewer is correct: the previous code adapted the super-twisting gains $K_1,K_2$, whereas the manuscript adapted the model parameters. The previous adaptation law was also not implementable, because it was written in terms of $\tilde{\bm{\theta}}$, which depends on the unknown true parameters. Both manuscript and code now adapt the model parameters
\begin{equation*}
\theta_{1,i}=\frac{1}{\kappa_{u,i}},\qquad \theta_{2,i}=\frac{\kappa_{v,i}}{\kappa_{u,i}},\qquad i\in\{x,y\},
\end{equation*}
while the super-twisting gains are fixed. The new law uses only measured signals and is driven by the integral state $\nu_i$ of the super-twisting algorithm:
\begin{equation*}
\dot{\hat{\bm{\theta}}}_i=\Proj_{\Theta}\Big(-\Gamma\,\bm{\phi}_i^{\top}\,\sat_{\bar\nu}(\nu_i)-\sigma\big(\hat{\bm{\theta}}_i-\bm{\theta}_{0}\big)\Big),\qquad \bm{\phi}_i=[\,a_i\ \ v_i\,],
\end{equation*}
active only when $|s_i|\le s_{\mathrm{on}}$, i.e., once the sliding mode has been reached. Once $s_i\equiv0$, the closed loop forces $\nu_i=\bm{\phi}_i\tilde{\bm{\theta}}_i+\delta_i/\kappa_{u,i}$, i.e., the integral state reconstructs the equivalent control. The law is therefore a gradient estimator on the parameter error, whose convergence requires persistent excitation of $\bm{\phi}_i$. The projection keeps $\hat{\kappa}_{u,i}>0$ and bounds $\hat{\bm{\theta}}_i$. Theorem~2 has been rewritten for this law (see our response to Comment~3).
 
\item \textbf{Nominal parameters.} The previous text reported $\hat{\kappa}_u=0.5$ and $\hat{\kappa}_v=0.75$, whereas the code used different values. All values actually used are now listed in Table~\XX. The main results use the nominal value implied by the velocity-command interface (unit static gain, $\kappa_u=\kappa_v=1/\tau$, $\tau=0.4$~s), i.e., $\bm{\theta}_0=[0.4,\ 1.0]^\top$. A new experiment (Section~\XX, Table~\XX) initialises the estimates at the previous ``arbitrary'' values, $\hat{\bm{\theta}}_i(0)=[2.0,\ 1.5]^{\top}$, which are also used as the prior of the $\sigma$-modification, for payload masses of 0.05, 0.10, 0.20 and 0.30~kg, and compares fixed and adaptive parameters.
 
\item \textbf{Reproducibility.} A single script, \texttt{run\_paper\_experiments.m}, regenerates every figure and table without manual reconfiguration. The co-simulation runs in real time and is not strictly deterministic, so each case is repeated five times and reported as mean $\pm$ standard deviation. Payload velocities and all swing metrics are now computed from the simulator ground truth, not from the cable-rate estimate. An equation-to-code correspondence table is included in the repository (\texttt{EQUATION\_MAP.md}).
\end{enumerate}

\end{reply}

\begin{point}
The outer-loop dynamics in Eqs. (16)–(17) are not derived from the UAV–payload system. From the preceding kinematic equations, the cable-error dynamics do not follow as \(\dot{\tilde h}_h=-K_h\tilde h_h+\xi_h\). The physical pendulum dynamics required to establish this equation are missing, and the definition of \(\xi_h\) appears circular because it includes the cable-error derivative itself. Consequently, Theorem 1 does not establish stability of the proposed UAV–payload closed loop. In addition, a claim of global exponential stability is incompatible with the small-inclination and quasi-static assumptions, which define a local operating regime.
\end{point}

\begin{reply}
We sincerely thank the reviewer for this rigorous and insightful analysis. The reviewer is absolutely correct on all points: our previous formulation abused the kinematic abstraction, leading to a circular definition of the perturbation term, an overreach in the stability claims of Theorem 1, and an undeniable contradiction regarding Global Exponential Stability. We have thoroughly rewritten the "Closed-Loop Error Analysis" section to address these critical flaws. The modifications are detailed below:1. Correction of the Cable-Error Dynamics and Circularity: We agree that forcing the cable-error dynamics into a first-order equation ($\dot{\tilde{h}}_h = -K_h\tilde{h}_h + \xi_h$) by hiding the physical pendulum acceleration ($\ddot{\theta}$) inside the perturbation term $\xi_h$ created an algebraic loop. To correct this, we have abandoned the flawed first-order simplification. The revised manuscript now explicitly introduces the time-scale separation between the fast inner velocity-tracking loop and the slower outer kinematic loop. The perturbation term $\xi_h$ has been rigorously redefined to depend only on strictly external or pre-determined bounded signals: the observer estimation error ($\mathbf{e}_h$) and the inner-loop velocity tracking error ($\tilde{\mathbf{v}} = \dot{\mathbf{x}} - \mathbf{v}_c$). By removing $\dot{\mathbf{h}}$ from the definition of $\xi_h$, the circularity has been entirely eliminated.2. Redefinition of Theorem 1 (Scope of Stability): The reviewer rightly pointed out that Theorem 1 did not prove the stability of the complete physical UAV-payload system. We have revised Theorem 1 to clarify its actual scope. The theorem now formally establishes the Input-to-State Stability (ISS) of the outer kinematic layer, treating the unmodeled higher-order pendulum dynamics and the inner-loop tracking errors as bounded non-vanishing perturbations. We now explicitly state that Theorem 1 validates the kinematic reference generation, while the stability of the physical interconnected system relies on the robustness of the dynamic compensator (addressed in Section [Insert Section Number]).3. Correction from Global to Local Stability: We apologize for the oversight regarding the global stability claim. As the reviewer correctly noted, any model relying on a small-angle approximation ($\Vert{}\mathbf{h}_h\Vert{}/l \ll 1$) and quasi-static behavior is inherently restricted to a local operating regime. We have corrected "Global Exponential Stability (GES)" to "Local Exponential Stability (LES)" (and regional ISS for the perturbed case) throughout the manuscript. The proofs have been updated to explicitly define the domain of attraction $\mathcal{D}$, which is strictly bounded by the physical validity of the small-inclination assumption. All these changes have been highlighted in Section [Insert Section Number] of the revised manuscript. We believe these corrections provide the mathematical rigor that the previous version lacked, and we are grateful to the reviewer for pointing out these foundational issues. 

\end{reply}
